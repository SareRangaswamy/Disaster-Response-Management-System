 # 🚨 AI Disaster Response Management System

A Java-based intelligent disaster response system that analyzes emergency situations and automatically allocates rescue teams, disaster-specific resources, and shelter capacity using a rule-based AI decision engine.

## 🚀 Features

- 🤖 Rule-based AI priority analysis
- 🚨 Automatic emergency prioritization
- 👨‍🚒 Rescue team allocation
- 📦 Disaster-specific resource allocation
- 🏠 Shelter capacity management
- ⚠️ Custom exception handling
- 📚 Java Collections
- 🔎 Java Streams API
- ✅ Input validation
- 🌊 Flood response
- 🔥 Fire response
- 🏚️ Earthquake response
- 🔄 Dynamic user input

## 🧠 AI Decision Engine

The system uses a **rule-based AI decision engine** to analyze:

- Disaster type
- Severity
- People affected
- Injured people

The engine calculates a priority score and automatically determines the appropriate response.

```text
Emergency Input
      ↓
Input Validation
      ↓
AI Analysis
      ↓
Priority Score
      ↓
Priority Level
      ↓
Rescue Team Selection
      ↓
Resource Allocation
      ↓
Shelter Allocation
      ↓
Response Result
